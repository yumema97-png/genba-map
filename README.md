# 現場マップ

工事現場を完成（消防検査）までの残り日数で色分けして地図に出し、現場で訪問記録・写真・進捗を残すためのスマホ向けページ。

- 地図ページ：`index.html`（Vercel で公開 https://yashima-genba.vercel.app/ ）
- データ：Googleスプレッドシート「現場マップDB」
- 裏側：`gas/Code.gs`（スプレッドシートに紐付けた Apps Script）

## 仕組み

```
Excel（共有サーバー → Googleドライブ同期）
   │ 週1で GAS が読み込み（importFromExcel）
   ▼
スプレッドシート「現場マップDB」
   物件      … Excelから取り込み（自動で上書き）
   物件追加  … 消検日・建築確認検査日・搬入・工事進捗メモ（アプリで入力、消えない）
   訪問記録  … 行くたびに1行（日時・記録者・建物進捗・メモ・写真・GPS）
   設定      … パスワード・記録者・Excelファイル名・現地判定の距離
   ▲
   │ 読み書き（GAS ウェブアプリ）
index.html（Vercel）
```

## ピンの色

消検日（物件追加に入力）があればそれを、なければ消検月（月末扱い）を基準に、今日からの残り日数で決める。

| 色 | 残り日数 |
|---|---|
| 赤 | 60日以内 |
| 黄 | 90日以内 |
| 青 | 120日以内 |
| 灰 | それ以降 |
| 白（点線） | 消検未定 |
| 薄灰 | 完成済（初期は非表示） |

- 訪問記録がある現場は薄く表示＋チェックマーク
- 消検日（日付）が入っている現場は、ピンの横に「消検 11/10」のような札が付く（枠も少し太い）
- しきい値は `index.html` 冒頭の `BANDS` で変更できる

## 初回セットアップ

### 1. スプレッドシート
1. ドライブの「現場マップDB」を開く（物件シートに初期データ入り）
2. 拡張機能 → Apps Script を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 関数 `setup` を実行（初回は権限の許可が出る）→ 物件追加・訪問記録・設定シートができる
4. 設定シートを書き換える
   - パスワード：部内で共有する簡単なもの
   - 記録者：カンマ区切り（例 `横山,高橋,小松`）
   - Excelファイル名：ドライブに同期されるExcelのファイル名
   - 現地判定m：ピンからこの距離以内なら「現地」と表示（初期300）
5. 左の「サービス」の＋ → **Drive API** を追加（Excel読み込みに必要）
6. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 実行するユーザー：自分
   - アクセスできるユーザー：全員
   - デプロイ → 表示される **ウェブアプリのURL** をコピー

### 2. 地図ページ
1. `index.html` の `GAS_URL = 'PASTE_GAS_WEBAPP_URL_HERE'` を上のURLに差し替えて push
2. Vercel で GitHub のリポジトリを Import（設定はそのまま、Application Preset は Other）。main に push するたびに自動で反映される
3. 公開URL https://yashima-genba.vercel.app/
4. スマホで開いて「ホーム画面に追加」しておくとアプリのように使える

### 3. 週1の自動更新
Apps Script の トリガー（時計アイコン）→ トリガーを追加
- 実行する関数：`importFromExcel`
- イベント：時間主導型 → 週ベースのタイマー → 曜日と時間を選ぶ

手で更新したいときは `importFromExcel` を直接実行する。

## 使い方（現場で）
1. ピンをタップ → 下から物件の詳細が出る
2. 「訪問を記録」で建物の進捗を選び、メモ・写真を付けて「記録する」
   - 位置情報を許可しておくと、ピンからの距離が自動で付く
3. 「物件情報（手入力）」で消検日・建築確認検査日・搬入・自社工事の進捗メモを保存
4. 上の色チップで表示を絞る。「未訪問のみ」「元請」「現場名検索」も使える
5. 右下「一覧」で完成が近い順に並ぶ

## 注意
- 位置は現場名から推定した丁目の中心（概算）。住所が分かったら物件シートの住所列を直して緯度・経度を空欄にすると、次回取り込み時に座標を取り直す
- 住所が読めない現場は「要確認」列に印が付き、地図には出ない（一覧には出る）
- Excel側で現場名を変えると別物件扱いになる。訪問記録は現場名で紐付いているため
- 写真はドライブの「現場写真」フォルダに溜まる（リンクを知っている人は閲覧可）
- リポジトリは Public。物件データやパスワードはスプレッドシート側にあり、リポジトリには入っていない
